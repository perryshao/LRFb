## 结论

可以采用 Cross-View-Learning 的分层验证策略，而且本次已实际执行：原 MATLAB
函数的受限语法树执行、独立数值公式对照、原 C/C++ 编译检查，以及 Python 串联的小型流水线。
主方法在非退化合成数据和少量真实 IP 数据上能完成描述子、GMM、Fisher 和分类计算。
**这不等于原 MATLAB 驱动可以直接完整运行，也不等于论文准确率已经复现。**

验证共 19 组：15 组检查通过，4 组按预期复现已知错误。后者是缺陷证据，不能计作算法正确。

## 已用执行证据确认的问题

1. **圆心 MEX 的输出越界。** AddressSanitizer 在只分配一个输出槽位时捕获
   `stack-buffer-overflow`。原 `Estimate_Frenet` 就是单输出调用。
   为继续验证几何公式，数值测试适配器明确请求三个输出；这是测试中的隔离措施，
   原 MATLAB 调用问题仍未修复。
2. **四元数及池化退化输入。** 实际执行 `Myrotm2quat` 的 180° 旋转输入及
   `fv_pooling_ts` 的空序列输入，均得到非有限值。
3. **采样补齐越界。** 实际执行 `rand_sampling_ts`：每条序列 6 帧、请求每条 13 帧时越界。
   该代码只允许把原随机索引补一遍。测试使用固定排列，不声称复现 MATLAB 随机数序列。
4. **回归梯度错误。** 实际目标函数在单参数 `theta=2`、仅启用第二正则项时，
   返回导数约 2，而中心有限差分约 4，确认缺少系数 2。

这些问题没有通过测试替身修正或隐藏。其他静态问题仍见 [CODE_REVIEW.md](CODE_REVIEW.md)。
